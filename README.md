# arismoko/horizon

> [!IMPORTANT]
> **Development here is slowing down and will stop.** Aria and a few others from the mod team are moving to [Sunrise](https://playsunrise.net) ([sunrise-org/sunrise](https://github.com/sunrise-org/sunrise)).

This fork built Horizon's mod API: native hooks, the `Host`, handles, Parts, attachments, mod loading and WebAssembly mods. That work is now one pull request to Horizon: [horizon-rust/horizon#16941](https://github.com/horizon-rust/horizon/pull/16941). Once it lands, the mod API lives upstream.

Until then, this repository gets bug fixes only, and nothing new starts here. Open issues and pull requests stay readable, and the [book](https://arismoko.github.io/horizon/) and [releases](https://github.com/arismoko/horizon/releases) stay up.

Thank you to everyone who built, ported, tested and reviewed here.

Horizon itself is at [horizon-rust/horizon](https://github.com/horizon-rust/horizon). The code in this repository is under the same licence as Horizon's ([LICENSE](LICENSE)).
