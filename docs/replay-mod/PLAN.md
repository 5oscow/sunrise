## Implementation order for the owning team

1. Pin a **published post-deletion SDK** and set up the signed-SDK CI smoke path in `sunrise-replay`: DCO, self-hosted `REPLAY_CI_RUNNER`, no secrets, package/publish through `sunrise-mods` only after signing is agreed. Carry only Sunrise-owned original feature code and required notices. Split sources into `archive/` (`.mcpr`, privacy scrub, bounded ZIP handling/recovery), `record/` (ordered observed stream + synthetic avatar), `play/` (index, clock, peer, lifecycle), `editor/` (camera, splines, timeline, markers/annotations), `browser/`, `native/` (small pin-specific adapters) and localized `assets/`.
2. Port the archive/clock/recovery units and their tests before coupling to Game. Preserve archive `camera.json`/markers and opaque entries across atomic saves; enforce existing decompression limits. In capturing, lock/fence snapshot registration against receive append; write timestamp zero Login → center → pose → resident chunks, then ordered live deltas. Disarm before finalize and reject stale callbacks. Preserve anonymization and private chat/identity/credential filters. Distinguish archive policy (deliberately excludes certain packets) from observation coverage (must not quietly omit them).
3. Prove ordinary isolated memory playback with a synthetic stream/known packets before the UI: timestamp zero, pause, speed, seek both directions, close, invalid input leaves current view usable, never writes to a real server/world or fetches arbitrary pack URLs. No live-socket replay overlay. Handle local view identity/generation on close, disconnect/replacement and startup cancellation. Only then port timing/camera tracks and editor controls, staged lines, HUD and list. Wire both command usages after deletion and verify exact suggestions/dispatch and conflict behavior. Use only generic fixes from `MOD-API-GAPS.md` if approved; the release is not green while a required item is red/unrun.
4. Re-run on the pinned signed SDK without relying on any deleted feature APIs; add privacy-preserving logs of markers/counts, test real window interaction/focus and bounded synthetic archives, and verify no mod installed restores stock visuals, commands and input. Existing project parity capture stays with the deletion owner (`sunrise-bots --capture`); no vanilla resources, logs with vanilla data, screenshots or release keys in the mod repository.
